# 三元动量波控策略 V1.0

选定版本 `cash_t14_v20`，规则版本 `tri-momentum-vol-v1.0-20261014`。策略05，独立于旧核心ETF回归动量策略及线上四资产轮动。

- 资产按固定顺序为纳指513100、沪深300 510300、黄金518880。简单动量20个价格点（19段收益）；最高者胜出，全负不空仓。
- 赢家20段日收益的样本标准差乘√252；风险仓位 `min(1,0.14/sigma)`，其余现金、收益0，不加杠杆。缺数据拒绝计算，不填充。
- 每周最后实际交易日收盘附近人工执行，前一交易日收盘数据决定标的及权重。14:50只作公开报价辅助，不用实时价格改变模型。
- 单边10bp，买卖金额分别收费；同标的调整权重也收费。非调仓日仓位自然漂移。

## 页面与数据

`/tri-momentum-vol-control/` 复用净利润断层页面的主题与共享导航。详情按钮含概述、冻结回测、逐年归因、净值/回撤/风险仓位悬停联动和区间滑条。底部周度记录分为冻结回测、历史延伸、定版后模型，均非真实成交。

`data/backtest.json`、`data/nav.csv` 是2019-01-02至2026-09-18的冻结研究，不被夜间更新覆盖。1873日及395次周度记录逐项与原研究对账。`data/live.json` 提供前收信号、预览/最终状态和Wind Excel交易日历。夜间只发布live/history/rebalances三个文件。

## 独立运行

1. 开机、当前Windows用户登录，Wind已登录、Excel WDF.Addin可用。Python需numpy、pandas、requests。
2. GitHub鉴权优先读取用户环境的GITHUB_TOKEN，缺失才读取已有git凭据。脚本不打印、不新建或复制凭据。
3. 手动运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File strategies/tri_momentum_vol_control/run_update.ps1`。
4. `register_task.ps1` 注册 `TriMomentumVolControl-Nightly-1810`。只创建该新任务；不修改其他自动化。18:10每天触发，周末跳过；节假日可刷新到最近收盘日。无Codex/模型服务依赖，无下单接口。
5. `logs/nightly_*.log` 为单次执行日志；成功必须同时满足新run_id、Wind数据完整、Pages本次commit构建built、线上三份数据一致。失败记录在本地data/runs中，保留上次成功latest。

盘中网页每30或60秒直接获取三只ETF腾讯公开行情，跨域读取已验证；不是逐笔/交易所直连服务，没有时效或可用性承诺。可执行参考只在周内最后交易日14:50–15:00、前收最终信号有效、三只ETF当日报价不超过120秒、盘口有效时显示。数据过期、报价失败、日历越界均停止提示。网页无需本机或Codex在线即可刷新价格，但日线模型仍依赖夜间本机任务。

## 证据边界

历史为多轮研究后用户选定，非独立样本外或实盘业绩。复权收盘为总回报代理，未覆盖整手、拒单、盘口容量、分红到账延迟和实际滑点。14%不是回撤上限；公开行情当前收盘后验证不等于盘中链路已验证。未连接券商，不知道用户实际资金、持仓和成交；记录不能当作用户交易账本。
